# Amey Pandit — Creative Portfolio

Next.js App Router portfolio using React, TypeScript, Tailwind CSS, Motion, GSAP/ScrollTrigger, React Three Fiber and Lucide React.

## Run locally

```powershell
npm install
npm run dev
```

## Verify and build

```powershell
npm run lint
npm run typecheck
npm run build
npm start
```

Node.js 20.9 or newer is required by current Next.js. The optional Three.js scene is dynamically loaded; its visual meaning is not required to understand the page. See `docs/technical-architecture.md` for animation ownership and fallback behavior, and `docs/content-inventory.md` for provenance and limits on project claims.
